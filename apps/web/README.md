# TenantPilot web (Next.js 16)

Control-plane UI: customers, onboarding, agent console with approvals, run traces,
knowledge, connectors, tool governance and audit log.

```bash
npm ci
npm run dev        # http://localhost:3000, proxies /api/* to API_INTERNAL_URL (default http://localhost:8000)
npm run build      # standalone output used by the Dockerfile
```

`/api/*` is served by `src/app/api/[...path]/route.ts`, a same-origin proxy to FastAPI
(read at request time). In Kubernetes the Ingress routes `/api` straight to the API.
`AGENTS.md` / `CLAUDE.md` are generated by `next dev`.
